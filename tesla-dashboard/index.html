Read-only by design. This page displays data but contains no lock, start, climate or charging commands. Tokens are kept in this browser session and are never saved in the repository. Avoid entering a Tesla token on shared devices.
Data connection

Dashboard setup

  1. Create and register an application in the Tesla Developer portal.
  2. Authorise it with vehicle_device_data and optionally vehicle_location.
  3. Paste a short-lived access token below. It remains in sessionStorage only.
  4. The dashboard will list your vehicles, then request read-only vehicle_data. It never wakes the vehicle.
Not written to localStorage, GitHub or the service-worker cache.
The endpoint must allow CORS from this GitHub Pages origin. Supports Tesla Fleet API-shaped JSON, Fleet Telemetry fields and simple flat JSON.
Fleet API calls may be billed. One minute is the recommended starting point.
